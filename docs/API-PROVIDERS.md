# API 平台与自定义模型

本功能参考 [Chatbox 的服务商配置结构](https://github.com/chatboxai/chatbox/blob/main/docs/technical/ai-providers.md)，将连接、模型配置与请求协议分开实现。本期支持内置 DeepSeek 和 OpenAI 兼容 Chat Completions 接口。

## 配置平台

打开「设置 → 数据管理」中的 API 服务商配置。内置 DeepSeek 保留原有 Key 保存方式及模型选择；可以添加多个自定义平台，分别保存连接地址、Key 与模型列表，再选择当前使用的平台。

自定义平台填写：

| 项目 | 示例与含义 |
| --- | --- |
| 平台名称 | 自己辨认用的名称，例如「我的网关」 |
| API Base URL | 例如 `https://gateway.example.com/v1`；填写自己的地址。只填根地址时会补 `/v1`，粘贴完整 `/chat/completions` 地址时会识别其基础路径。 |
| Chat 接口路径 | 默认 `/chat/completions`，相对 Base URL 拼接；网关使用其他 Chat Completions 路径时可修改。 |
| API Key | 对应平台的 Key；本地无鉴权兼容服务可留空。 |
| 允许 HTTP | 仅在使用可信网络中的 `http://` 接口时开启。HTTP 会明文传输 Key 和对话。 |
| 模型 ID | 实际提交给服务端的字符串，例如自己的网关提供的模型 ID；需与平台支持的 ID 一致。 |
| 显示名称 | 可选，仅用于界面显示；不改变实际请求中的模型 ID。 |

内置 DeepSeek 及官方 `api.deepseek.com` 地址默认显示 `deepseek-flash`、`deepseek-v4-pro`。其他地址使用自己配置的模型，不会根据名称中出现 DeepSeek 就推测平台类型。

在模型下拉框选择「自定义…」可打开配置入口。已保存的平台各自记住最后选择的模型。长名称显示缩略，实际请求仍发送完整模型 ID。

## 测试与保存

「测试连接」使用平台的模型列表接口（Base URL 下的 `/models`），不产生聊天请求。部分网关不提供此接口；模型列表测试失败时仍可保存有效的手动配置，实际模型 ID 以对应平台文档为准。

保存并应用后，下一次聊天、重新生成、压缩摘要及记忆提取使用当前平台。正在生成、导入、上传或有未完成保存时会阻止改连接；设置草稿在关闭弹窗或切换设置页后保留。编辑地址或 Chat 路径后需重新填写对应 Key，无鉴权服务可留空。原 Key 只对其原地址与路径复用。

续写或附件失败重试保留原服务商身份。切换了平台后，应切回原平台继续原回答，或用「重新生成」让当前平台生成新回答。

## 功能范围

内置 DeepSeek 保留深度思考开关、联网搜索、附件及语音接口。自定义平台本期支持文字聊天、流式思考内容展示、长对话压缩和跨对话记忆；DeepSeek 专用的上传、搜索、语音及思考请求开关会禁用，并且不会向自定义平台发送 DeepSeek 扩展字段或文件 ID。历史附件在自定义文字上下文中使用不可用提示。

OpenAI 兼容不代表支持 Anthropic Messages、Gemini、Responses 或厂商私有协议；本期不包含这些适配。压缩与记忆会额外请求所选平台，产生该平台的相应用量。

## 数据与真机连接

DeepSeek 原 Key 保持在原有本机安全存储。Android 将自定义平台的地址、Key、模型列表和当前平台作为独立整体通过 AndroidKeyStore 加密保存；浏览器使用当前站点的 localStorage。聊天记录仅保存模型 ID 与平台路由 ID，不保存平台地址或 Key，历史 ZIP 不包含连接密钥。

模型 API 地址与聊天数据存储服务器是两个独立配置。选择自建存储不会改变模型请求地址；选择模型平台也不会切换聊天的本地/服务器存放位置。

真机连接电脑上的兼容服务时，Base URL 填电脑的局域网 IP，例如 `http://192.168.1.10:1234/v1`，并保证手机可访问该端口。`127.0.0.1` 在手机上指手机自身。外网使用可达的 HTTPS 地址。

Android 自定义接口使用原生 HTTP 流式传输，正常校验证书并禁止重定向转送凭据；不需要关闭系统证书验证。浏览器运行时仍受目标服务 CORS 配置约束。

本次验证使用虚构凭据与本机合成 API，并覆盖取消、错误、中文分片、模型 ID、鉴权、连接保存和摘要路由。未使用模拟器或用户真实 Key；真机上的完整网络链路仍需实际设备验证。
